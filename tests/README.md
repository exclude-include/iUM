# 🧪 Tests Directory

## Test Files

- `test_chroma.py` - ChromaDB 테스트 (레거시)
- `test_supabase_vector.py` - Supabase pgvector 테스트
- `test_embedding.py` - 임베딩 모델 테스트
- `test_embedding_batch.py` - 배치 임베딩 테스트
- `test_folder_creation.py` - 폴더 생성 기능 테스트
